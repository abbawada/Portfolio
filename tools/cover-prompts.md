# Game-cover art prompts (paste into ChatGPT, one per project)

Updated for the vector-chrome build: the spine band, serial, rating box, AW
monogram and author name are now mounted in code over the art, so the art must
not contain them. Attach the project's real photo to each prompt so the art is
grounded in it. After generating, check all four corners for watermarks before
sending to me.

## Master prompt (prepend to every project line)

Create video-game box cover art, PlayStation-3-era in spirit but with NO
console branding, NO logos, NO wordmarks, NO rating marks, NO serial numbers,
NO monograms, and NO author or studio name. The ONLY text permitted is the
project title as the hero type treatment; every other mark is overlaid in code
later. Portrait 2:3, 1024x1536. Painterly photographic realism, dramatic
single-source lighting, restrained palette built around warm paper (#f7f5f0),
ink black (#141414), and one gold accent (#c6a15b). Keep the leftmost 12% of
the frame quiet and dark (a printed spine band overlays it). Keep the bottom
20% calm (badges overlay both bottom corners). One clear hero subject, centered
or right-of-center, cinematic depth, no clutter, no borders, no frames, no
watermark.
